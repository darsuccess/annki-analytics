Как добиться consistent design (один продукт с разных ракурсов)

  1. Midjourney --sref + --cref: используй reference-изображение. Сгенерируй лучший ракурс, затем используй его как style reference для остальных.
  2. Leonardo AI Elements: обучи Element на нескольких изображениях продукта. Все последующие генерации будут следовать стилю.
  3. Flux fine-tuning: для максимального контроля -- обучи LoRA на 10-20 изображениях продукта. Все генерации будут точно воспроизводить дизайн.
  4. Seed-based подход: используй один seed + вариации ракурса в промпте (front view, side view, 3/4 view, top-down view).

2. AI для 3D-моделей

Инструменты генерации 3D

Meshy AI

Free: 100 кредитов/мес | Pro: $20/мес (1000 кредитов) | Max: $120/мес

Лидер рынка. Быстрая итерация, batch-генерация, multi-view image-to-3D. Экспорт: FBX, GLB, OBJ, STL, USDZ, BLEND.

Для мебели -- одно из лучших решений: хорошо передаёт текстуры дерева и ткани.

Рекомендация: основной инструмент для 3D-моделей pet-линейки.

Tripo 3D

Free: 300 кредитов/мес | Pro: $19.90/мес | Advanced: $49.90/мес

Чистая quad-топология (хорошо для web). Экспорт: OBJ, GLTF, GLB, FBX (на платных планах). Image-to-3D и text-to-3D.

Tripo v3.0 Ultra -- существенный скачок качества в 2026.

Хорош для web-моделей с правильной топологией.

3D AI Studio

По кредитам, 25-35 кредитов за генерацию

Агрегатор: доступ к Meshy, Rodin, Tripo, CSM в одном интерфейсе. Экспорт: GLB, FBX, OBJ, USDZ, STL, DAE, BLEND.

Удобно для сравнения моделей разных движков.

TRELLIS 3D AI

Бесплатно

Полностью бесплатный конвертер изображений в 3D. Экспорт: GLB, OBJ, STL, GLTF, USDZ, PLY. Превью прямо в браузере.

Для быстрого прототипирования без затрат.

Качество для мебели

  • Простые формы (лежанки, подставки для мисок) -- генерируются хорошо, текстуры дерева и ткани передаются адекватно
  • Сложные формы (когтеточки с несколькими уровнями, домики) -- требуют ручной доработки в Blender
  • Rodin -- лучший для фотореалистичных объектов, но дороже
  • Meshy -- лучший баланс скорости и качества
  • Tripo -- лучшая топология для web-использования

Рекомендация: Google model-viewer

Минимальная интеграция -- пара строк HTML. Поддерживает GLB, автоматический AR на мобильных. Для pet-мебели в сканди-стиле это идеальный вариант: покупатель видит лежанку в 3D, крутит, и может "поставить" в свою комнату через AR.

<model-viewer src="/models/dog-bed-oak.glb" alt="Лежанка для собаки из дуба" ar camera-controls shadow-intensity="1" style="width: 100%; height: 400px;"> </model-viewer>

Workflow: промпт --> 2D --> 3D --> сайт

  1. Генерация 2D-изображения в Midjourney (белый фон, чёткий ракурс 3/4)
  2. Загрузка в Meshy AI (image-to-3D), генерация за 30-60 сек
  3. Экспорт в GLB
  4. Оптимизация в Blender (если нужно) -- уменьшение полигонов, правка текстур
  5. Загрузка на CDN, вставка через model-viewer на страницу товара

Видео с животными

Kling 3.0 + Sora 2 -- реалистичные животные

AI-модели 2026 года хорошо понимают физику движения животных: правильные тени, взаимодействие с поверхностями, естественные позы.

Что работает: кошка спит на лежанке, собака подходит к миске, кот точит когти -- базовые сценарии генерируются убедительно.

Что пока сложно: длинные взаимодействия (>10 сек), несколько животных в кадре, точное воспроизведение конкретной породы.

Промпт-пример:

5. Workflow: от идеи до готовой карточки товара

1

Концепт и дизайн (15 мин)

Инструмент: Claude / ChatGPT

Текстовое описание продукта: материалы, размеры, стиль, целевая аудитория. Генерация названия, описания, ключевых характеристик.

2

AI-рендер продукта (30 мин)

Инструмент: Midjourney v7 / Leonardo AI

Генерация 5-8 изображений: белый фон (4 ракурса) + в интерьере (2-3 варианта) + с животным (1-2). Итерации до идеального результата.

3

3D-модель (20 мин)

Инструмент: Meshy AI (image-to-3D)

Загрузка лучшего изображения с белого фона. Генерация 3D (30-60 сек). Экспорт в GLB. При необходимости -- правка в Blender (ещё 30 мин).

4

Видео-контент (20 мин)

Инструмент: Runway Gen-4.5 / Kling 3.0

Product rotation video (белый фон). Lifestyle video (продукт в интерьере с животным). 2-3 клипа по 5-10 сек для Reels/TikTok.

5

Описания и SEO (15 мин)

Инструмент: Claude

Описание для сайта (RU + EN). Описание для маркетплейсов. SEO-метаданные. Alt-тексты для изображений.

6

Сборка карточки товара (20 мин)

Инструмент: v0 / Cursor / CMS

Загрузка изображений, 3D-модели, видео. Заполнение описаний. Публикация на сайте и маркетплейсах.

8. Ограничения: что AI пока не может

Точные размеры и пропорции. AI не гарантирует соблюдение конкретных размеров. Если нужна лежанка 60x80 см, придётся итерировать и корректировать. Для 3D-моделей -- ручная правка масштаба в Blender.
Идеальная consistency между SKU. Даже с reference images и seed -- разные продукты могут выглядеть немного по-разному. Решение: fine-tuning (Flux LoRA / Leonardo Elements).
Сложные механизмы. Складные элементы, трансформеры, скрытые крепления -- AI генерирует визуально, но не гарантирует инженерную осмысленность.
Точное воспроизведение конкретных тканей/текстур. "Рогожка в конкретном артикуле" -- AI не воспроизведёт. Можно приблизиться через style reference и inpainting.
Длинное видео с животными. >10 секунд непрерывного реалистичного видео с животным -- пока артефакты. Решение: монтаж из нескольких коротких клипов.
3D-модели production quality. AI-генерированные 3D подходят для web-просмотра и маркетинга, но НЕ для производства (ЧПУ, 3D-печать деталей). Для производства нужны CAD-модели.
Юридическая чистота. Midjourney, Flux, Leonardo -- потенциальные вопросы с авторскими правами в России. Adobe Firefly -- единственный с полной юридической гарантией. Для коммерции в РФ риск минимален, но стоит отслеживать законодательство.
